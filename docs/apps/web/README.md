# Desenvolvimento da aplicação web

Este diretório receberá a documentação específica da aplicação
`apps/web`.

Conforme as decisões do projeto forem definidas, a documentação poderá abordar:

- organização de rotas, páginas e componentes;
- renderização e obtenção de dados;
- formulários e gerenciamento de estado;
- autenticação e autorização no cliente;
- acessibilidade e experiência do usuário;
- testes;
- execução local e operação.

Nenhum desses padrões está definido por este README. Registre somente decisões
confirmadas pelo contexto da aplicação e mantenha assuntos compartilhados com a
API ou outros apps na documentação de
[integrações](../../integrations/README.md).
